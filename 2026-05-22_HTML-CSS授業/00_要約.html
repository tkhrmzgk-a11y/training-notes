🧹リセットCSS（外部 vs 自作）

💡 やさしく解説

ブラウザの初期スタイルを打ち消すCSS。世の中に有名なリセットCSSがたくさんあり、ダウンロードして読み込むのもアリ。でも「何がリセットされるか」を理解せずに使うと、どこを直せばいいか分からなくなるので注意。

有名なリセットCSS特徴
ressモダンで使いやすい定番
The New CSS Reset新しめ。ほぼ全部リセット
normalize.css消しすぎず差を整える
sanitize.cssnormalize＋実用的な初期値
  • 便利そうだから読むのではなく、中身を何回か読んで把握してから使う
  • 難しい記述も入っているので、全部とは言わずともある程度は目を通す
  • 仕事では会社が独自のリセットCSSを1個持っているのが普通。就職したらそれに沿う

今回の講師例は最低限を自作：text-decoration消し、list-style: none、border-collapse/spacing、画像の width 調整など。

🪜制作手順とクラス命名

① 制作の順番

  1. HTMLの構造をサクッと作る（header / main-visual / section×4 / image / footer）
  2. リセットCSSを用意（読み込みだけ先に書く）
  3. style.cssを上から：外枠（body→header→main→footer）→各中身
🔑 「出来上がったら次」の積み上げ

ヘッダー完成 → メインビジュアル → キャンペーン → スケジュール → … と1ブロックずつ完成させて次へ。先生は完成したコードを折りたたんで隠す（見やすさのため）。

② クラス名の付け方

  • 共通のデザイン（同じ見た目のタイトル等）＝同じクラス名（例 section-title / section-container）で一括管理
  • 独自のもの＝セクション頭文字（Campaign→C、Schedule→S、Price→P、Reservation→R…）で C〇〇 のように
  • 「ここ同じデザインだな」と気づいたら共通クラスにまとめるチャンス
  • ※あくまで先生の流儀。他の付け方も不正解ではない

👀ちょこちょこ確認・画像の等倍/2倍

💡 一番大事な習慣

書いたCSSが頭の中のイメージ通りにブラウザに出ているかを、こまめに確認する。「margin書いたからすき間つく」「font-size上げたから大きくなる」——この感覚が育つと強い。先生でもちょこちょこ確認する。まとめ書きしてから間違い探しは大変だから。

画像の等倍・2倍（メモ必須）

  • 高解像度モニター（Retina等）で綺麗に見せるため、画像は2倍サイズで書き出して縮小表示することがよくある（バナー等）
  • 2倍画像をそのまま置くと大きく出るので、h1 などに width を明示指定して原寸に収める
  • 今回は練習なので等倍。実務では「ちょい大きめで送られてくる」前提を覚えておく

📦幅の継承・共通設定と上書き

💡 width:100% は上へ継承する

img { width:100% } ＝親要素の幅いっぱい。その親がさらに width 未指定なら、その上の親 → さらに上 → bodyまで遡って幅が決まる。だからメインビジュアルの画像は何も書かずとも画面幅いっぱいになる（リセットだけでうまくいく）。

例：img(100%) → .mv（幅未指定）→ main（幅未指定）→ body ＝ 画面幅。ブロック要素は親の幅を継承するのでこうなる。

中央配置と共通設定

/* 共通設定はCSSの上の方に */
.section-container {
    width: 70%;
    margin: 0 auto;       /* 左右autoで中央配置 */
    padding: 40px 0 60px;  /* 全セクション共通の上下余白 */
}
.section-title {
    border-bottom: 4px solid;  /* 見出し下の線は border（marginではない） */
    color: white;
}
📌 上書きは「下に書く」or「クラスの方が強い」

共通設定を上に書き、個別で変えたい所だけ下で上書き。.campaign期間 のようなクラスセレクターは要素セレクターより優先される（詳細度が高い）ので上書きできる。

🔤フォント系プロパティは孫まで継承

💡 やさしく解説

color / font-size / text-align / letter-spacing などの文字系プロパティは、子だけでなく孫・その先まで継承される傾向がある。だから親に color: white を1回書けば、中の文字が全部白くなる。

文字系（color等）

  • 孫・ひ孫まで継承される傾向
  • 親に1回書けば中身全部に効く

display: flex

  • 子要素までしか効かない
  • 孫は横並びにならない

※「絶対」ではなく「傾向」。でも実務では「文字色は親にまとめて書く」と覚えておくと楽。

セレクターが効かない時の対処

:not(:last-of-type) や :last-of-type が思った通り効かないことがある。そんな時は深追いせず：

  • div で囲んで、その中で :first-child 等を使う
  • またはクラス名を付けて直接上書き（確実）
