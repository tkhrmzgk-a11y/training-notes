⭐今日の最重要10項目

1

復習はベタ写しじゃない

同じ作りを真似しつつ、文字サイズや余白は自分で考える。学ぶのは「作り方・操作方法」。

2

ページを目的で分ける

デザインガイド／デザインカンプ。素材が多ければさらに スタイル一覧／コンポーネント一覧／素材 でも分けられる。

3

ノーイメージは保険

画像がないとレイアウトが崩れる。サイトに必ず1枚「ノーイメージ画像」を用意。会社名入りにすると気が利く。

4

ダミーテキストの定番

和文＝宮沢賢治（『野ねずみのノイズミ』等）／欧文＝Lorem Ipsum（ロレムイプサム）。業界では一択。

5

フォントは時間を切る

「3時間」「半日」と時間を区切って決める。仮決めOK、スタイル化しておけば後で一括変更できる。

6

Boldがあるか必ず確認

選んだフォントに太字（Bold）がないと、コーディング時に font-weight が効かない。Regular＋Boldの2種以上は必須。

7

サイズの定番セット

64・48・36・24・20・16・14・12。Figmaの「よく使われるフォント一覧」がこのセット。悩む前にコピペでOK。

8

Stylerで一括登録

レイヤー名がそのままスタイル名に。1個ずつポチポチが消える。Figmaのアクション→Stylerで実行。

9

見出しはH4まで

H5/H6はほぼ使わない。サイズがPタグ（16）と変わらず、Pでいいじゃんになるから。実用はH3、多くてH4。

10

真っ黒・真っ白を避ける

#000/#FFF はコントラスト強すぎ＋モニター差で不安定。ベースカラーに合わせて赤味・青味を少し足す。

📐ページ構成の整理（デザインガイド／デザインカンプ）

Figma の「ページ」を目的別に分けると整理しやすい。基本は 2ページ構成。

基本の2ページ構成
  1. デザインガイド：フォント・カラー・コンポーネント・素材などのルール集
  2. デザインカンプ：実際のページデザイン（トップ・アバウト・コンタクトなど）

もっと細かく分けたいとき

  • ワイヤーフレーム：構造設計のラフ
  • スタイル一覧：色・フォントだけのまとめ

  • 素材：アイコン・写真・イラスト等
A先生：これは自由 ページを細かく分けるか、1ページの中でフレームで整理するかは本人の考え方次第。プロジェクトの規模で決めればOK。

🖼️⚠️ ノーイメージ画像（画像なし時の保険）

サイトを作るときに 「画像が用意できない時の代替」 として絶対に持っておくべき1枚。

なぜ必要？ 更新型のサイト（WordPress等）で、サムネ画像が用意できないケースが必ず1回は出る。
例：喫茶店サイトでイベント記事を作るが、撮影が間に合わなかった など。
→ このとき画像なしのままだとカードのレイアウトが崩れる。
→ 保険として「ノーイメージ画像」を当てておく。

カードレイアウトの崩れイメージ

│ 本文     │  │ 本文      │  │ 本文     │

作り方のヒント
  • 「No Image」とテキストだけ入れた灰色背景の画像が定番
  • コーポレートサイトなら会社名・ロゴ入りがよくある
  • A先生の個人的おすすめ：つまんないノーイメージより、エッジが効いた・一癖あるデザインにする。「このサイト面白いな」と思ってもらえる可能性がある。アイデア勝負。

🔤フォント探しと和文・欧文ダミーテキスト

サイト用のフォントを決めるとき、A先生がいつもやる手順。

準備するもの

  • 適当なフレームを1個作る
  • 欧文・和文のダミーテキストを貼る（タイトル＋本文の両方）
  • そこにいろんなフォントを当てて、見比べながら決める

ダミーテキストの定番

和文：宮沢賢治（A先生の場合）
  • 『野ねずみのノイズミ』など、宮沢賢治の作品から抜粋
  • これは人それぞれ。「あの会社の社長メッセージ」等でもOK
欧文：Lorem Ipsum（ロレムイプサム）一択
  • 業界の定番中の定番。「これからWeb業界でやっていくなら死ぬほど見ることになる」（A先生）
  • 意味のないラテン語のテキスト。可読性に依存しないので純粋にフォントの見た目だけで判断できる
  • 「Lorem Ipsum ジェネレーター」等で大量に生成可能

フォント探しの場所

  • Google Fonts：無料・商用OK・Web実装も楽（最有力）
  • 絞り込み：Language＝Japanese、Categories＝Serif（明朝系を探すなら）
  • Figmaのテキストツール選択時の「よく使われるフォント一覧」もそのまま使える

💡フォント選びのコツ

★最重要：Bold（太字）があるか確認
  • 気に入っても Regular（標準）しかない フォントが意外と多い（特に欧文）
  • これだとコーディング時に font-weight: bold が効かない＝太字にできない
  • 太字を使う場面はWebでほぼ必須。タイトルや強調で使う
  • 最低でも Regular + Bold の2種類 あるフォントを選ぶ
  • 逆にウェイトが10種類とか多すぎるのも使い切れない。2〜3種類で十分
時間を区切って決める
  • フォント探しは「一瞬で時間が溶ける」（A先生）
  • 3時間・半日など事前に時間を決める
  • 仮決めでもOK。スタイル登録しておけば、後で違和感あれば元のフォントを変えるだけで一括変更できる
今ここに時間をあったら後で直せばいい、という感じなので覚えておいてください。── A先生

📏フォントサイズの定番セット

A先生がベースにする数値 64 / 48 / 36 / 24 / 20 / 16 / 14 / 12（px）

これはFigmaのテキストツール選択時に表示される「よく使われるフォント一覧」と同じセット。悩むぐらいなら、まずはこの中から必要なものを登録すればOK。

サイズ用途
64px巨大見出し（メインビジュアルのキャッチコピー等）
48px大きな見出し（セクションタイトル）
36px中見出し
24px小見出し
20px強調された本文・リード
16px本文（標準）
14pxキャプション・注釈
12px注意書き・コピーライト

足りなくなったら後から追加（例：40, 18, 10 など）して登録すればOK。

🧩Stylerプラグインで一括スタイル登録

サイズごとにスタイルを1個ずつ登録していくのは面倒。Stylerプラグインを使うと一気にまとめて登録できる。

使い方

  1. 下のツールバーの「アクション」から「Styler」を検索 → 保存（保存すれば次回以降ずっと使える）
  2. 登録したいテキストを作成（レイヤー名がそのままスタイル名になるのがポイント）
  3. レイヤー名は 見出し-64-Bold のように、後で見て分かる名前にしておく
  4. テキストを選択した状態でプラグイン → Styler → Generate Style
  5. サクッと一括登録完了
ディレクトリ化（フォルダ分け）
  • スタイル名に /（スラッシュ） を入れると、Figma側で自動でディレクトリ（フォルダ）扱いになる
  • 例：JP/見出し-64-Bold、EN/Heading-64-Bold
  • これで「JPフォルダ」「ENフォルダ」に分類されて見やすい
同じ機能のプラグインは他にもある Styler以外にも一括登録系プラグインは多数。アイコン挿入系プラグインも便利。作業時間を設けて色々試してみるのがおすすめ。

🪧見出しは H4 までが実用

HTMLの見出しタグ <h1>〜<h6> のうち、実際に使うのはH4までというのがA先生の話。

使用頻度の目安
  • H1〜H3：よく使う（A先生もこの範囲が多い）
  • H4：「結構使ってるな」という印象
  • H5/H6：ほぼ見たことがない
理由
  • H5/H6のデフォルトフォントサイズは16px（Pタグと同じ）
  • 「対コンピュータ・対ブラウザに『見出しです』と伝えられる」のは確かに意味あり
  • でも見た目はPタグと変わらない＝「だったらPでいいじゃん」になる
  • そもそも文章にそんなに見出しの階層は不要

Figmaでスタイル登録するときも、見出しは 4種類（H1〜H4相当） 用意しておけば十分。

🛠️受講者Eさんのトラブル：Web版でStyler動かない

症状 テキストを選んでスタイル登録しようとしても、スタイルが適用されない。タイポグラフィパネルからクリックしても反応なし。

切り分け（A先生のリモート対応）

  1. 画面共有で状況確認
  2. テキストを削除→書き直し→もう一度試す → 変わらず
  3. 他のスタイルでも同じか確認 → 同じ
  4. 原因に気づく：Web版（ブラウザのFigma）でやっていた
  5. 解決：Figmaアプリ版（デスクトップアプリ）で立ち上げ直す → 動いた
教訓
  • Figma Web版だとプラグインが入りきっていないことがある
  • ファイル複製の直後はWeb版で開くので、明示的にアプリ版を起動して開き直す
  • 普段からアプリ版を使うのが安全

🎨カラースタイル登録（5色設計）

フォント登録が終わったら、次は色。アタラヨデザインを参考に5色構成でスタイル登録する。

5色の内訳
  • メインカラー：サイトの主役の色（暖色系で1色）
  • サブカラー：メインに次ぐ色（メインと同系統＝暖色系で1色）
  • ブラック系：文字色など
  • ホワイト系：背景色など
  • グレー系：補助・区切り線等
トンマナの注意 アタラヨデザインのサンプルは暖色系（赤・茶）。
→ メイン/サブを青などの補色にすると全体のトーンが壊れる。
→ 真似する範囲を 「暖色系で2色」 までに守るのが無難。

仕上げのアイデア

  • 色チップだけでなく、グラデーション・透過（オパシティ）も置いておくと使い勝手UP
  • 色のイメージ画像／アートワークを1枚作っておくと、後でガイドを見返したときに「このサイトはこういう雰囲気だな」と一発で思い出せる（A先生おすすめ）

⚫真っ黒・真っ白は使わない（理由と対処）

A先生の鉄則 ブラック系・ホワイト系の色を作るとき、#000000 や #FFFFFF といった真っ黒・真っ白は基本使わない。
→ ベースカラーに合わせて少しだけ赤味・青味・緑味を足す。

2つの理由

理由詳細
① モニター差で不安定完璧な黒・完璧な白はモニターによってズレる。「世の中に完璧な黒と白は存在しない」
② コントラストが強すぎる純粋な #000 と #FFF を組み合わせるとコントラストが極端で、目に刺激を与える。長時間見ると疲れる

微調整の例

  • 赤系のサイト → 黒に少しだけ赤を足す（例：#1A0F0F 等）
  • 青系のサイト → 黒に少しだけ青を足す（例：#0F0F1A 等）
  • 緑系のサイト → 黒に少しだけ緑を足す（例：#0F1A0F 等）
  • 白も同様に微調整。一見しただけでは「ほぼ白／ほぼ黒」に見えるが、整って見える
パッと見の見分けは不要 微調整した黒・白は、一瞬で「真っ黒・真っ白」と判別できる。パッと見の見え方は変わらないが、仕上がりの質感が違ってくる。

  • ページをデザインガイド／デザインカンプに分ける
  • サイト用のノーイメージ画像を1枚用意（つまんないやつより一癖あるデザインで）
  • 和文・欧文フォントを時間を切って決める（3時間目安・仮決めOK）
  • 選んだフォントにBold（太字）があるか必ず確認
  • フォントサイズ 64/48/36/24/20/16/14/12 でスタイル登録（Styler使うと楽）
  • カラー5色（メイン／サブ／黒／白／グレー）を登録
  • 真っ黒・真っ白は使わない。ベースカラーに合わせて少しずらす
  • 色のイメージ画像・アートワークもガイドに添える（後で見返した時に分かりやすくなる）
  • Figmaはアプリ版を使う（Web版だとプラグインが動かないことがある）
