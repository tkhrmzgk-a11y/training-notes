🎯position absolute で中央にならない問題

💡 やさしく解説

親に position: relative、子に position: absolute; top:50%; left:50% を書いた時、子の左上の角が親の中央に置かれます。子の中心ではないのがミソ。だから「タイトル」が右下にズレて見える。

解決法は transform: translate(-50%, -50%)

子要素を自分の幅・高さの半分ぶん左上に戻すと、ようやく真の中央になります。

/* 親 */
.mv { position: relative; }

/* 子（真の中央配置） */
.mv h1 {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
📌 もう1つの中央配置法（フレックスボックス）

親に display: flex; justify-content: center; align-items: center; でも真ん中に置けます。シンプルなのでこちらが多用される。positionは「カンプから座標で位置を取りたい時」に強い。

手法使い所
flex で中央普通の中央配置。シンプル＆レスポンシブに強い
position absolute + translateカンプの座標どおりに置きたい時／重ねたい時
margin: 0 auto横方向のみ中央。ブロック要素＋widthが必要

🃏z-index で重なり順を決める

💡 やさしく解説

position を付けた要素同士はレイヤー（重ね順）が発生します。あとに書いた要素ほど前面。これだとヘッダーがメインビジュアルに隠れちゃう。z-index で順番を上書きできます。 

.header-container {
    position: fixed;
    z-index: 9999;  /* 絶対に前面に出したい */
}
  • 数字が大きいほど前面（小さい数字は後ろ）
  • z-index は position（relative/absolute/fixed/sticky）が付いた要素にしか効かない
  • 現場で 9999 がよく使われる。「とにかく一番前」のおまじない
  • 細かく管理するなら 1, 2, 3 や 10, 20, 30 で段組み

🧭ヘッダーを作る（ロゴ＋ナビゲーション）

💡 やさしく解説

<header> の中にもう1個 <div class="header-container"> を作って、CSSは中の div に書く——これが現場の癖。ヘッダー自体に直接書かないのは、後で位置調整や背景色を分けやすくするため。

HTML構造

<header>
  <div class="header-container">
    <h1><img src="img/logo.png" alt="ロゴ"></h1>
    <nav class="h-nav">
      <ul>
        <li><a href="#">top</a></li>
        <li><a href="#">about</a></li>
        /* … 5個ぶん繰り返し */
      </ul>
    </nav>
  </div>
</header>

CSS（フレックスで左右両端＋縦中央）

.header-container {
    width: 100%;
    padding: 8px 64px;      /* 上下8px、左右64px */
    display: flex;
    justify-content: space-between;  /* ロゴとnav を左右両端に */
    align-items: center;          /* 縦方向ど真ん中 */
}
.h-nav ul { display: flex; }     /* ナビのli を横並びに */
🔑 :not(:last-of-type) で「最後以外」に余白

リンクとリンクの間に 64px 開けたい時、最後の li だけ余白なし＝の書き方：

.h-nav li:not(:last-of-type) {
    margin-right: 64px;
}

:not(セレクタ)＝「○○以外」を選ぶ。:last-of-type＝「同じタグの最後のやつ」。組み合わせて「最後以外」を一括指定。

📌ヘッダーを上部固定（position: fixed）

💡 やさしく解説

スクロールしてもヘッダーが画面の上に張り付くやつ。position: fixed で実現します。fixed は親のrelativeに左右されない（ブラウザ画面が基準）のがabsoluteとの違い。 

.header-container {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    z-index: 9999;   /* 絶対前面 */
}
値基準スクロール時
fixedブラウザ画面位置が動かない（張り付く）
absolute親の relativeスクロールと一緒に動く
relative元あった位置スクロールと一緒に動く
stickyスクロール位置ある場所まで来たら張り付く

訓練校の公式サイトのヘッダーも fixed。今いる場所にヘッダーが追従するタイプ。

🖼メインビジュアル（背景画像＋中央タイトル）

💡 やさしく解説

画面いっぱいの背景画像の上にタイトルをカンプ通りの位置に配置する。カンプを見て「上から160px、左から120px、幅600px」のように数字を読み取り、position: absolute で座標指定する流れ。 

.mv {
    width: 100%;
    height: 100vh;             /* 画面高さいっぱい */
    background: url(img/hero.jpg) center/cover no-repeat;
    position: relative;          /* 中の要素の基準にする */
}
.mv-content {
    position: absolute;
    top: 160px;
    left: 120px;
    width: 600px;
    color: white;
}

背景指定のショートハンド：background: 画像URL 位置 / サイズ 繰り返し;。今回は url(...) center/cover no-repeat＝中央配置・はみ出してでも全面を覆う・繰り返さない。

📐 ピクセルパーフェクトは追わない

ブラウザ幅とカンプ幅が違うので完全一致は不可能。ほぼ一緒なら大丈夫。Figma側で Optionキーを押しながら要素をホバーすると、要素間の距離が表示される（スマートガイド）。

✏️5時間目の演習（教科書123p）

1時間で自力でレイアウトを組む練習。教科書から画像だけ引っ張ってきて、HTML/CSSは今までの知識で書く。

  • 背景色は茶色系（好きな色でOK）
  • リンクの色も自由
  • ナビゲーション全体に 60px のパディング
  • 各リンクに 0.5em（半文字分）のパディング＝クリック領域を広げる
  • その他の余白は気にしすぎなくてOK、数字が書いてある所だけ守る
💡 演習のコツ

外側から内側へ書いていく。footerタグ → footer-containerの位置決め → 中の各要素の見た目 → 細かい余白。完成形を頭に入れてからCSSを書き始めると迷子にならない。

🦶フッターを作る（address / tel: / small / &copy;）

今日の新しいタグ・テクニック

タグ／属性意味・使い所
<address>ページ制作者・会社の連絡先（住所・電話・メール）。自動でイタリック表示になる
font-style: normaladdress のイタリックを戻したい時
<a href="tel:00-0000-0000">クリック／タップで電話アプリ起動。スマホなら直接かけられる
<small>コピーライト表記の慣習。日本のサイトはほぼこれで囲う（海外は span が多い）
&copy;マルシ（©）の特殊文字。直接「©」を書くと文字化けの可能性。&copy; のほうが安全

HTML構造

<footer>
  <div class="footer-container">
    <img src="img/logo.png" alt="Natural Coffee">
    <address>
      <p><span>〒101-0051</span> 東京都千代田区神田神保町1丁目105</p>
      <p><a href="tel:00-0000-0000">00-0000-0000</a></p>
    </address>
    <ul class="f-address">
      <li><a href="#">トップ</a></li>
      /* … 6個ぶん */
    </ul>
    <small>&copy; MdN Corporation.</small>
  </div>
</footer>
📌 nav タグはフッターでは使わない（慣例）

<nav> はサイトのメインのナビゲーション（＝ヘッダー側のグローバルナビ）に使うのが通例。フッターのリンク一覧は nav を使わず直接 ul。

🎯セレクター応用：最後以外を一括指定

💡 やさしく解説

フッターは「ロゴ・住所・ナビ・コピーライト」のかたまりが縦に並んでいて、間隔がすべて 20px。1個ずつmarginを書くのは面倒。子要素全部に「margin-bottom:20px、ただし最後だけ0」を一括で指定できる書き方が便利。 

/* footer-container の直下の全要素、ただし最後の type 以外 */
.footer-container > *:not(:last-of-type) {
    margin-bottom: 20px;
}
  • >＝直接の子要素のみ（孫まではいかない）
  • *＝あらゆる要素（全部）
  • :not(:last-of-type)＝最後のタグ以外
  • 組み合わせて「直下の子要素ぜんぶ、ただし最後以外」を1行でカバー
🔑 セレクターを使いこなすほどCSSが短くなる

先生から共有されているCSSセレクター チートシートをブックマークしてすぐ見れるようにしておくと、こういうテクニカルな選び方ができるようになる。

👆Aタグの padding でクリック領域を広げる

リンクの周りに padding を付けると、その範囲もクリックできるようになる（リンクのアタリ判定が大きくなる）。

.f-address a {
    padding: 0.5rem;   /* 上下左右に半文字分 */
}
  • パソコンだけならそこまで気にしなくてOK
  • スマホの時こそ大事＝指でタップしやすい大きさにする（ユーザーフレンドリー）
  • 緑のハイライト部分（DevToolsで見える padding 範囲）まで反応する

📐テキスト・要素の中央寄せまとめ

目的書き方
テキスト・インライン要素を中央text-align: center; を親に
ブロック要素を横方向中央margin: 0 auto;＋width 指定
子要素を縦横ど真ん中（flex）display: flex; justify-content: center; align-items: center;
絶対座標で真ん中（position）top:50%; left:50%; transform: translate(-50%,-50%);

フッターの白い枠を中央に置く時は margin: 0 auto、中の文字を中央揃えにする時は text-align: center。両方使う場面が多い。
