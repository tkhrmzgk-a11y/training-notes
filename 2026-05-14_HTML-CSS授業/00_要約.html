🧹リセットCSS・複数クラス

💡 やさしく解説

ブラウザは勝手に余白などを付けます。それを打ち消すCSS＝リセットCSS。
reset.css（打ち消し担当）と style.css（デザイン担当）に分け、reset → style の順で読み込む（下が優先なので後で上書き）。 

<link rel="stylesheet" href="css/reset.css">
<link rel="stylesheet" href="css/style.css">
📌 数字クラス名はNG

「box1」だと何の1か伝わらない＆順番が固定される。primary / secondary など意味のある名前を。共通スタイルは1クラスにまとめるのが賢い。

💬コメントアウト

コードを一時的に無効化＆メモする機能。Cmd + /（Mac）/ Ctrl + /（Win）。

/* CSSのコメント */
<!-- HTMLのコメント -->
⚠️ 注意

HTMLのコメントはDevToolsで丸見え。未公開情報・大事なことは書かない（2ヶ月後のセール情報を隠す→バレる）。

📁フォルダ構成・index.html（図解あり）

💡 やさしく解説：index.html を直下に置く理由

サーバーは直下の index.html を自動で開く機能を持っています。だから example.com/ だけでトップが表示されURLが短くなる。top.html だと example.com/top.html まで打つ必要があります。

フォルダ構成の図解

プロジェクト/
├── index.html        ← 直下に置く（自動で開かれる）
├── about/
│   └── index.html    → example.com/about/
├── css/
│   ├── reset.css
│   └── style.css
└── img/
    └── photo.jpg

CSSは css/、画像は img/ にまとめる。正解はなく就職先のルールに従う。

🧭相対パス vs 絶対パス

相対パス

  • 今のファイルから見た位置
  • css/style.css / ../img/a.png
  • プロジェクト内の参照

絶対パス

  • フルURL
  • https://.../style.css
  • 外部サーバー・Webフォント

../ ＝1つ上の階層に戻る。「ドサッ／」と覚える（先生ネタ）。

🏗セクションタグ・H1ルール

💡 やさしく解説

<h1> は1ページに1回だけ（一番大きな見出し＝サイトのタイトル）。2つ目以降は h2, h3 と下げる。<section> の中には必ず見出し（h*）を1つ入れる。

タグは入れ子（親子）が基本。クロスさせるのはNG：

/* ○ OK */
<div><p>文</p></div>
/* ✕ NG（クロス） */
<div><p>文</div></p>

🖼画像の置き方（img / background）

<img src="img/shinjuku.jpg" alt="新宿の夜景">
  • 閉じタグなし
  • src＝画像までのパス、alt＝代替テキスト（音声読み上げ用。できる限り入れる）
  • 意味のある画像＝img、背景＝CSSのbackground
  • figure/figcaption＝独立した画像＋キャプション、picture/source＝画面幅で画像切替
💡 object-fit: cover

width/heightを無理に指定すると画像が潰れる。object-fit: cover でアスペクト比を保ったままトリミング。フリー素材はUnsplashなど、ダウンロードしたらリネームして img/ にまとめる。

🎨色彩の基礎（RGB / CMYK）

RGB（加法混色）

  • Red/Green/Blue（光の三原色）
  • モニター表示
  • 混ぜるほど明るく→白
  • Webは必ずこれ

CMYK（減法混色）

  • シアン/マゼンタ/イエロー/黒
  • 印刷物
  • 混ぜるほど暗く→黒
  • Webでは使わない
📌 色の3属性

色相（色の種類）・明度（明るさ）・彩度（鮮やかさ）。無彩色＝白黒灰、有彩色＝色味のあるもの。

♿色覚特性への配慮

💡 やさしく解説

日本人の男性は約20人に1人、女性は約500人に1人が色覚特性を持ちます。
→ 色だけに頼らないデザイン（アイコン・形・動きでも区別できるように）が大切。検査は病院の「石原式」。Web画面では正確に測れません。

🎯配色の3色設計（図解あり）

💡 やさしく解説：補色

色相環で正反対の色＝補色（黄↔紫、青↔オレンジ）。馴染ませたい→近い色、目立たせたい→補色。例：NBAレイカーズは黄×紫（補色）で文字がくっきり。

サイトの3色設計（図解）

ベースカラー
約70%（背景・土台）
メインカラー
約25%（ブランド色）
5%
役割割合使い所
ベースカラー約70%背景など土台。彩度低めが多い
メインカラー約25%サイトの印象＝ブランド色。ボタン等
アクセントカラー約5%強調したい所だけ。補色で視線を奪う

配色パターン：モノクロ／ダイアード（補色2色）／トライアド（3色）／類似色／スプリットコンプリメンタリー。配色サイトはあくまで「きっかけ」、そのまま使わず微調整を。
