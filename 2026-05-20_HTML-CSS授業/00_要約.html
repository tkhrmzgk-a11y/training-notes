▦テーブル（表組）を作る

💡 やさしく解説

表は4種類のタグを組み合わせて作ります。先に「どんな表か」を紙やFigmaで描いてからタグに置き換えると迷いません。なお、テーブルは昔レイアウト作りに使われましたが、今はflex/gridがあるのであまり使いません。

タグ意味
<table>表全体をまとめる
<caption>表のタイトル
<tr>テーブルロー＝1行。trの数＝行数
<th>テーブルヘッド＝見出しセル
<td>テーブルデータ＝通常セル

th / td は必ず tr の中に入れる（行の中のセルだから）。

<table>
  <caption>バーベキュー料金比較</caption>
  <tr><th> </th><th>コスパ</th><th>ボリューム</th></tr>
  <tr><th>金額</th><td>3,000円</td><td>5,000円</td></tr>
</table>
🔑 セル間の隙間をなくす2行（リセットの定番）

テーブルに border をつけると線が二重になる。これを整えるお決まりの記述：

table {
    border-collapse: collapse;   /* 隣り合う線を1本にまとめる */
    border-spacing: 0;        /* セル間の余白を0に */
}
⚠️ テーブルの注意点

各trのセル数は必ずそろえる（1行だけ2個や4個はNG＝表が崩れてCSSも効かなくなる）。これがテーブルが嫌われる理由の1つ。THに幅を指定すると同じ列の下のセルも連動して伸びる。

⊞セルの結合（colspan / rowspan）

Excelやスプレッドシートのようにセルをくっつけられます。th / td の属性で指定。

属性意味
colspan="2"横に2セル分結合（→ 同じtrのセルを1つ減らす）
rowspan="2"縦に2セル分結合

イメージは「結合」というよりセルを伸ばす感じ。先生いわく、昔の訓練校のサイトはテーブル＋colspan/rowspanだけでレイアウトしていて、1か所間違えると全体が崩れて編集が大変だった——だから今は無理に使わない。

▥グリッドレイアウト（CSS Grid）

💡 やさしく解説

flexの2.0版のようなもの。flexが「横並び（1次元）」が得意なのに対し、グリッドは縦と横の両方（2次元）をマス目で一気に組めます。写真ギャラリーのような格子状の配置が得意。

flex と grid の違い

flexbox

  • 1次元（横並びが基本）
  • 横3つ＋横3つにしたい時は親要素を2個に分ける
  • シンプルで使いやすい

grid

  • 2次元（縦横同時）
  • 親要素1個で縦横まとめて配置できる
  • 覚える量が多い・概念が難しい

基本の書き方

.container {
    display: grid;
    grid-template-columns: 320px 320px 320px;  /* 列（横） */
    grid-template-rows: 240px 240px;          /* 行（縦） */
    gap: 10px;     /* マス目同士のすき間（marginは使わない） */
}
  • grid-template-columns ＝書いた数だけ横に列が増える
  • grid-template-rows ＝書いた数だけ下に行が増える
  • display:grid を付けただけでは何も起きない＝列・行を自分で書く必要がある
🎮 おすすめ：ゲームで学べる「Grid Garden」

先生が紹介。ゲーム感覚でグリッドに慣れられるサイト。flexbox版（Flexbox Froggy）もあります。深く考えず慣れるのがコツ。

📐fr単位でレスポンシブ

💡 やさしく解説

ピクセルで列幅を固定すると計算が面倒だし画面幅で崩れる。グリッド専用の単位 fr（fraction＝割合）を使うと「1対1対1」のような比率で幅を決められます。料理の「醤油：みりん：酒」の割合のイメージ。 

.container {
    width: 100%;
    max-width: 1000px;
    grid-template-columns: 1fr 1fr 1fr;  /* 3等分 */
}
/* スマホ：999px以下は2列に */
@media screen and (max-width: 999px) {
    .container { grid-template-columns: 1fr 1fr; }
}

最大1000px・gap込みなら 1fr＝約320px に自動計算してくれる。列幅をピクセルで書かなくて済むのが楽。

📨フォームの仕組み（フロントとサーバー）

💡 やさしく解説

お問い合わせ・会員登録などの入力フォーム。見た目（フロント）はHTML/CSSで作れるけど、入力された内容をサーバーに保存したりメール通知する部分はプログラミング（PHPなど）が必要。今回は見た目だけを作ります。

🔒 セキュリティとSSL（https）

フォームは住所・電話・決済情報など大事な情報を扱うので、サーバー側はガチガチのセキュリティが必要（だからこれを0から作れる人は給料が高い）。サイトは http ではなく https（SSL対応）にする。やり方はレンタルサーバーの管理画面でSSLをオンにするだけ。

用語：私たちがやるHTML/CSS側＝クライアントサイド（フロント）、処理する側＝サーバーサイド。

🧩フォームのタグ（input / label / select / textarea）

フォームは <form> タグの中に部品を並べて作ります。これらは教科書70pのインタラクティブコンテンツの仲間。

① form タグ（土台）

<form action="program.php" method="post"> … </form>
  • action＝送り先（PHPなどのファイル）。今は気にしなくてOK
  • method＝送り方。post（中身を隠す）が基本。getは入力内容がURLに出て丸見えなのでフォームには使わない

② input ＋ type属性（万能の入力部品）

大体の入力欄は input 1つで作れる。type 属性の値でブラウザが見た目を変えてくれる。input は閉じタグなし。

type の値できる部品
text1行テキスト入力
emailメール形式（@がないと弾く）
password入力が隠れる（●●●）
telスマホで数字入力モードになる
checkbox複数選択できる
radio1つだけ選択できる
submit送信ボタン
button汎用ボタン

③ label の for と input の id を一致させる（必須テク）

🔑 毎回使うテクニック

<label for="username"> と <input id="username"> の文字列を一致させると、ラベルの文字をクリックしても入力欄が反応する（紐付け）。または <label> で <input> を囲んでもOK。

<label for="username">お名前</label>
<input id="username" type="text" name="userName">

④ ラジオボタンの name は同じにする（重要なミス防止）

同じ質問のラジオボタンは name 属性を全部同じにする。1つでも違うと別グループ扱いになり、複数選べてしまう（ラジオは1つだけ選ぶものなのに）。

  • name＝プログラミング用のグループ名。同じグループ＝同じname
  • value＝送信される値（画面の文字ではなくこの値がサーバーに届く）
  • checked＝最初から選択状態にする（ラジオ）

⑤ select ＋ option（プルダウン）

<select>
  <option>商品について</option>
  <option selected>採用について</option>  /* selected=最初に表示 */
</select>

⑥ textarea（複数行入力）

お問い合わせ内容など長文用。input は1行だけなので、複数行は <textarea>。閉じタグあり。

⑦ 送信ボタン（submit / button）

  • <input type="submit">＝送信ボタン（value の値がボタンの文字に）
  • <button> タグ＝CSSが書きやすいので実務ではこちらも多い
📌 placeholder（うっすら灰色の文字）

placeholder="田中 太郎" で入力欄に薄い見本文字。ただし最近は非推奨ぎみ（入力済みと勘違いして送信しちゃう人がいるため）。label ではなく input に書く。

🎨フォームのデザイン（CSS）

🔥 フォームの幅は800px以下（最重要）

フォームを画面幅いっぱい（90%など）で作ると、入力欄がビヨーンと伸びて首や目が左右に動いてストレスになる。だから max-width: 800px くらいに収める。世の中のフォームも大体1000px以下。

レイアウトの作り方

  • 1問ずつを .form-item でまとめ、flexで横並び（ラベル｜入力欄）
  • フォーム全体は margin: 0 auto で中央寄せ、白背景＋padding で枠に
  • 入力欄は width: 100% ＋ font-size: 16px（入力文字を大きめに＝使いやすさ）
  • スマホ（768px以下）は display: block で縦並びに組み替え

属性セレクター

/* type="text" の input だけを狙う */
input[type="text"], input[type="email"] {
    display: block;
    width: 100%;
    font-size: 16px;
}

属性と値を [ ] でセレクターにできる。クラスを振っても同じことができる（先生は実務ではクラス派）。

♿ display:none で消すのはNG

凝ったフォームは標準デザインを display:none で全消しして作り直すことがあるが、キーボード操作のフォーカスができなくなる。キーボードでフォームを使う人（元エンジニア等）もいるので、元のスタイルを活かして装飾する方が良い。いじりすぎない。

必須マークは dt::before { content: "◆"; } で表示。ボタンは :hover で色を変えるアニメも。
