🧩ブロック要素 vs インライン要素

💡 やさしく解説

タグには2つのタイプがあります。
ブロック要素＝「四角い塊」（段ボール箱のイメージ）。インライン要素＝「文の中の一部分」（マーカーで引く感じ）。

📦 ブロック要素

  • div p header main nav footer h1〜h6
  • 幅・高さをCSSで指定できる
  • 指定しないと親要素の幅いっぱい（最終的にbody幅）
  • 後ろで段落が落ちる

📝 インライン要素

  • span strong small
  • 幅・高さ指定できない（一部例外）
  • テキストの分だけの幅
  • 改行されない（文中に並ぶ）
⚠️ 例外タグ

img＝インラインなのに幅高さ指定OK。a＝親のタイプを引き継ぐ。この2つだけ特別、と覚える。

🛠デベロッパーツール（F12）

💡 やさしく解説

ブラウザに最初から付いている「中身を調べる・その場で試す」道具。
F12 か 右クリック→検証で出ます。コーディング力はこれの使いこなしで決まります。

  • 左にHTML、右に効いているCSSが見える
  • CSSを直接書き換えて実験できる（保存はされない＝安全）
  • チェックボックスを外すと一時的に無効化 → どのCSSが優先か（打ち消しチェーン）が見える
  • 歯車 → Language → Japanese で日本語化できる
  • 表示位置は右/下/別ウィンドウから選べる（下が見やすい）
✅ プロのやり方

DevToolsで色・余白をリアルタイム調整 → 「これだ」と決まったらVSCodeにコピペ。試行錯誤の時間が激減します。

🧱ウェブページの構造

① ヘッダー：ロゴ・ナビ・検索窓
② グローバルナビ：サイト内リンク（基本ヘッダー内）
③ メインカラム：メイン内容（画像・カルーセル・地図など）
④ フッター：コピーライト・リンク

カラム数

1カラム

1列。スマホ対応が楽。初心者推奨。

2カラム

メイン＋サイド。コーポレートサイト。

3カラム

情報量多いサイト。スマホ対応大変。

📐デザインの4大原則

デザインの土台中の土台。これを意識するだけで読みやすさが激変します。

1

近接（Proximity）

関係ある要素は近づける、関係ないものは離す。

2

整列（Alignment）

端や中心をそろえる。バラバラはNG。

3

反復（Repetition）

同じパターンをくり返す。一貫性で信頼感。

4

対比（Contrast）

差をつけて強弱。見出しは大きく太く。

これはウェブに限らず部屋の整理整頓にも使えるレベル。引き出しのフォークとスプーンと箸が整理されてますか？それと同じ話。— A先生

👁Z型・F型視線

人の目は Z や F の形に動きます（5/11で詳しくやった内容の復習）。

Z型

  • 初めて見るサイト全体をざっと見る
  • 左上→右上→左下→右下

F型

  • 記事など読むとき
  • 左から右、少し下げてまた左から

大事な情報は左上〜左寄りに。コンビニの陳列と同じ原則。

🖼画像の種類（ビットマップ vs ベクター）

📷 ビットマップ（写真系）

  • JPEG / PNG / GIF / WebP
  • 小さい点の集まり
  • 拡大すると荒くなる
  • 写真・複雑な色が得意

📐 ベクター（図形系）

  • SVG
  • 数式で描く
  • 拡大しても荒れない
  • ロゴ・アイコンが得意

Web用は解像度72dpi・RGB。CMYKは印刷用なので無視でOK。

🖥モニターと画像サイズ

🔥 サイトが重い原因 No.1

画像のサイズ調整をしていないこと。
1500pxの画像をCSSで300pxに縮小して使うと、フォルダが膨らんで読み込みが遅くなる。「使うサイズに事前リサイズ」が鉄則。

  • サムネ等＝実寸サイズ（300pxなど）でOK
  • メインビジュアル＝モニターの1.5〜2倍を用意（3000px級）
  • 主なモニター：フルHD 1920×1080 が最多

🎨色の指定（3種類）

💡 やさしく解説

CSSで色を指定する方法は3つ。① 16進数 #ff0000　② RGB rgb(255,0,0)　③ RGBA rgba(255,0,0,0.5)（透明度つき）。

🟠 先生の板書（Figma）の図解

下が先生の手書き板書です。rgb(赤の値, 緑の値, 青の値) で各0〜255。rgb(255,0,0)=赤、rgb(255,255,255)=白、rgb(0,0,0)=黒。RGBAの4つ目「アルファ」＝不透明度。16進数は #000000=黒 / #ffffff=白 / #ff0000=赤。

図解（先生の板書をそのまま）

① 16進数（いちばん使う）

p { color: #ff0000; }  /* 赤 */

# の後 2桁ずつが R・G・B。各 00〜FF（＝0〜255）。略記もOK：#ff0000 → #f00。

② RGB

.t { color: rgb(255, 0, 0); }

RGBは混ぜると白くなる（光の三原色）。絵の具（CMYK）は混ぜると黒。逆です。

③ RGBA（透明度つき）

.overlay { background: rgba(0, 0, 0, 0.5); }
⚠️ 透明度はRGBAのみ

アルファ値：0＝透明、0.5＝半透明、1＝不透明。16進数では透明度を指定できないので、透明にしたい時は rgba() を使う。

色決めは Google「カラーピッカー」や Coolors が便利。モニターによって色は微妙に違って見えるので注意。
